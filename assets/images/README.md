browser). The site references these exact filenames — replace any file in place
to update it, no HTML changes needed.

## Notes
- The logo is used for the browser-tab favicon as well. If you want a crisper
  tab icon, add a small square `favicon.png` and update the two
  `<link rel="icon">` tags.
- To rename a piece or reword a caption, open `index.html` / `gallery.html` and
  edit the `data-title` / `data-meta` / `<h3>` text grouped beside each image.
- Originals were uploaded as resized WebP exports; if you have higher-resolution
  versions, drop them in over these (same filenames) for sharper display.
